<h1 align="center">Scoricomb@home</h1>
<div align="center"><i>calculate all NFL score permutations for a given final score</i></div>
<hr />
Scoricomb@home builds off of <a href="https://github.com/mechanikate/scoricomb">my previous work with combing through NFL score permutations</a> so that multiple people can contribute their compute for much faster combing.

<h2>Backend</h2>
The backend is built on <a href="https://github.com/expressjs/express">express</a> with various plugins to support large uploading of score permutations.
<h2>Frontend</h2>
The frontend is built in pure HTML5 which, although technically inefficient, works surprisingly fast compared to previous solutions.
